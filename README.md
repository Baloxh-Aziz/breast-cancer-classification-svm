# Breast Cancer Classification Using SVM

Classifies breast cancer tumors as malignant or benign using a Support Vector Machine (SVM).

## Dataset
Built-in sklearn `load_breast_cancer` dataset — 569 samples, 30 features  
Only first 2 features used: `mean radius` and `mean texture`

## What the notebook does
1. Loads the breast cancer dataset from sklearn
2. Selects first 2 features for visualization
3. Trains an SVM model with RBF kernel (C=1)
4. Plots the decision boundary with scatter plot

## How to run
1. Install dependencies: `pip install -r requirements.txt`
2. Open `Breast_Cancer_Classification_Using_SVM.ipynb` in Jupyter
3. Run all cells
